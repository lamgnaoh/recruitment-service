# Recruitment Service

Recruitment Service is a Spring boot framework with some features like
- RESTFul API
- JWT Authentication, Authorization
- Caching using Redis
- Monitoring tools like Prothemeus, Grafana
- Docker
- And maybe implement some CI/CD or Kubernetes for automating deployment, scaling, and management of
containerized applications (later)
